# Contributing

For reproducibility questions, include the command, Python version, operating system, input-verification output, and the full traceback in a GitHub issue. Avoid including personal or confidential event logs.

Keep numerical changes separate from documentation changes. Explain any changed target, split, feature availability rule, random seed, or scenario factor. Run the input checks and tests before proposing a change. Add a focused regression test when fixing an input-handling or numerical-consistency defect.

Do not overwrite reference results to hide a discrepancy. Explain the different environment or protocol and retain enough metadata to compare runs.
